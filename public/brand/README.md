# Aset merek — Janji Pengharapan

Letakkan file di sini dengan **nama persis** seperti di bawah; kode sudah
mengarah ke path ini, jadi cukup timpa filenya tanpa mengubah apa pun.

| File                    | Dipakai di                          | Saran ukuran        |
|-------------------------|-------------------------------------|---------------------|
| `logo.svg`              | Header, footer, admin panel         | SVG, monokrom       |
| `logo-full.svg`         | Header versi lebar (logo + tulisan) | SVG                 |
| `favicon.ico`           | Tab browser (taruh di `src/app/`)   | 32×32               |
| `icon.png`              | PWA / Apple touch (`src/app/`)      | 512×512             |
| `og-image.jpg`          | Preview saat dibagikan ke WA/IG     | 1200×630            |

Foto untuk hero, event, dan artikel taruh di `public/images/`.
Gambar yang di-upload lewat admin panel tersimpan di Supabase Storage, bukan di sini.
